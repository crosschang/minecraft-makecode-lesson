# 🌳 마인크래프트 에듀케이션 코딩: 채팅 명령어로 참나무 만들기

## 오늘의 미션

마인크래프트 에듀케이션에서 채팅창에 **`1`** 을 입력하면,  
플레이어 옆에 **참나무 한 그루**가 자동으로 만들어지도록 코딩해 봅시다!

우리는 이 활동을 통해 다음 내용을 배울 수 있습니다.

- 채팅 명령어로 코드를 실행하는 방법
- 내 위치를 기준으로 블록을 놓는 방법
- `pos(x, y, z)` 좌표의 의미
- `blocks.place()`와 `blocks.fill()`의 차이
- 여러 층으로 나뭇잎 모양을 설계하는 방법

---

## 완성 모습 상상하기

이 코드는 플레이어 위치에서 **오른쪽으로 2칸 떨어진 곳**에 나무를 만듭니다.

- 줄기: 참나무 원목 블록 5개
- 잎: 아래쪽은 넓고, 위쪽은 좁아지는 나뭇잎 모양

```text
        🍃🍃🍃
      🍃🍃🍃🍃🍃
    🍃🍃🍃🍃🍃🍃🍃
        🪵
        🪵
        🪵
        🪵
        🪵
```

> 실제 게임 속에서는 입체적인 3D 나무로 만들어집니다.

## 전체 코드

아래 코드를 마인크래프트 에듀케이션의 MakeCode 자바스크립트 편집기에 입력하세요.

```typescript
player.onChat("1", function () {
    blocks.place(LOG_OAK, positions.add(
        player.position(),
        pos(2, 0, 0)
    ))
    blocks.place(LOG_OAK, positions.add(
        player.position(),
        pos(2, 1, 0)
    ))
    blocks.fill(
        LEAVES_OAK,
        positions.add(
            player.position(),
            pos(0, 2, -2)
        ),
        positions.add(
            player.position(),
            pos(4, 3, 2)
        ),
        FillOperation.Replace
    )
    blocks.fill(
        LEAVES_OAK,
        positions.add(
            player.position(),
            pos(1, 4, -1)
        ),
        positions.add(
            player.position(),
            pos(3, 4, 1)
        ),
        FillOperation.Replace
    )
    blocks.fill(
        LEAVES_OAK,
        positions.add(
            player.position(),
            pos(1, 5, 0)
        ),
        positions.add(
            player.position(),
            pos(3, 5, 0)
        ),
        FillOperation.Replace
    )
    blocks.fill(
        LEAVES_OAK,
        positions.add(
            player.position(),
            pos(2, 5, -1)
        ),
        positions.add(
            player.position(),
            pos(2, 5, 1)
        ),
        FillOperation.Replace
    )
    blocks.place(LOG_OAK, positions.add(
        player.position(),
        pos(2, 2, 0)
    ))
    blocks.place(LOG_OAK, positions.add(
        player.position(),
        pos(2, 3, 0)
    ))
    blocks.place(LOG_OAK, positions.add(
        player.position(),
        pos(2, 4, 0)
    ))
})
```

## 1. 코드를 실행하는 비밀 버튼: `player.onChat()`

```typescript
player.onChat("1", function () {
    // 이 안에 있는 코드가 실행됩니다.
})
```

`player.onChat("1", ...)`은 플레이어가 채팅창에 **`1`** 이라고 입력했을 때  
중괄호 `{ }` 안의 코드를 실행하라는 뜻입니다.

### 해보기

1. 코드를 실행합니다.
2. 마인크래프트 채팅창을 엽니다.
3. `1`을 입력하고 전송합니다.
4. 플레이어 옆에 나무가 생기는지 관찰합니다.

---

## 2. 좌표 이해하기: `pos(x, y, z)`

마인크래프트 세상은 좌표로 이루어져 있습니다.

```typescript
pos(x, y, z)
```

| 좌표 | 의미 | 예시 |
|---|---|---|
| `x` | 옆으로 이동 | `2`이면 옆으로 2칸 |
| `y` | 위아래 이동 | `5`이면 위로 5칸 |
| `z` | 앞뒤로 이동 | `-2`와 `2`는 앞뒤 방향으로 넓히기 |

이 코드에서는 줄기를 다음 위치에 만듭니다.

```typescript
pos(2, 0, 0)
pos(2, 1, 0)
pos(2, 2, 0)
pos(2, 3, 0)
pos(2, 4, 0)
```

모든 줄기의 `x`와 `z` 값은 같고, `y` 값만 점점 커집니다.  
즉, 같은 자리에서 **위로 쌓아 올리는 것**입니다.

---

## 3. 블록 한 개 놓기: `blocks.place()`

```typescript
blocks.place(LOG_OAK, positions.add(
    player.position(),
    pos(2, 0, 0)
))
```

이 코드는 다음 순서로 읽을 수 있습니다.

1. `player.position()` : 지금 내 위치를 찾습니다.
2. `pos(2, 0, 0)` : 내 위치에서 옆으로 2칸 이동합니다.
3. `positions.add()` : 두 위치를 더해 실제 블록 위치를 정합니다.
4. `blocks.place(LOG_OAK, ...)` : 그곳에 참나무 원목 한 개를 놓습니다.

### 줄기 관찰하기

| 원목 번호 | 위치 | 설명 |
|---|---|---|
| 1번 | `pos(2, 0, 0)` | 가장 아래 줄기 |
| 2번 | `pos(2, 1, 0)` | 아래에서 두 번째 |
| 3번 | `pos(2, 2, 0)` | 나뭇잎 속 줄기 |
| 4번 | `pos(2, 3, 0)` | 나뭇잎 속 줄기 |
| 5번 | `pos(2, 4, 0)` | 꼭대기 가까운 줄기 |

---

## 4. 넓은 영역 채우기: `blocks.fill()`

나뭇잎을 한 칸씩 놓으면 코드가 아주 길어집니다.  
그래서 `blocks.fill()`을 사용해 시작 위치부터 끝 위치까지 한 번에 채웁니다.

```typescript
blocks.fill(
    LEAVES_OAK,
    시작위치,
    끝위치,
    FillOperation.Replace
)
```

- `LEAVES_OAK` : 참나무 잎 블록
- 시작 위치와 끝 위치 : 잎으로 채울 상자의 두 꼭짓점
- `FillOperation.Replace` : 그 공간에 있던 블록을 잎으로 바꾸기

---

## 5. 나뭇잎은 어떻게 생겼을까요?

### 첫 번째 잎 층: 크고 풍성한 아래쪽 잎

```typescript
pos(0, 2, -2)
pos(4, 3, 2)
```

- 높이: `y = 2`부터 `y = 3`까지, 총 2층
- 너비: `x = 0`부터 `x = 4`까지
- 깊이: `z = -2`부터 `z = 2`까지

따라서 줄기 주변을 감싸는 **가장 큰 잎 덩어리**가 됩니다.

### 두 번째 잎 층: 조금 작은 위쪽 잎

```typescript
pos(1, 4, -1)
pos(3, 4, 1)
```

높이 `y = 4`에서 3칸 × 3칸 크기의 잎을 만듭니다.

### 세 번째와 네 번째 잎 층: 나무 꼭대기

```typescript
pos(1, 5, 0) ~ pos(3, 5, 0)
pos(2, 5, -1) ~ pos(2, 5, 1)
```

위에서 보면 십자 모양의 잎이 만들어집니다.

```text
    🍃
  🍃🍃🍃
    🍃
```

이렇게 아래는 넓고 위는 좁게 만들면, 훨씬 나무다운 모양이 됩니다.

## 6. 코드 실행 순서 살펴보기

코드는 위에서 아래로 차례대로 실행됩니다.

| 순서 | 실행되는 일 |
|---:|---|
| 1 | 줄기 아래쪽 원목 2개를 놓습니다. |
| 2 | 큰 나뭇잎 영역을 채웁니다. |
| 3 | 위쪽 나뭇잎 영역을 채웁니다. |
| 4 | 꼭대기 십자 모양 잎을 만듭니다. |
| 5 | 잎 안쪽에 줄기 원목 3개를 다시 놓습니다. |

### 왜 원목 일부를 마지막에 놓을까요?

큰 잎 영역을 먼저 채우면, 줄기가 있어야 할 위치도 나뭇잎으로 바뀔 수 있습니다.  
그래서 마지막에 원목을 다시 놓아 **잎 속에서도 줄기가 보존되도록** 합니다.

## 7. 실습 방법

### 준비하기

1. 마인크래프트 에듀케이션을 실행합니다.
2. 새 월드를 만들거나 코딩 활동 월드에 들어갑니다.
3. `C` 키 또는 코드 연결 메뉴로 MakeCode를 엽니다.
4. 자바스크립트 모드에서 전체 코드를 붙여 넣습니다.
5. 실행 버튼을 누릅니다.

### 나무 심기

1. 나무가 생길 공간이 충분한 평평한 곳에 섭니다.
2. 채팅창에 `1`을 입력합니다.
3. 내 위치 옆에 생긴 나무를 관찰합니다.
4. 다른 장소로 이동해 다시 `1`을 입력하면 나무를 더 심을 수 있습니다.

> 나무는 플레이어의 현재 위치를 기준으로 만들어집니다. 벽이나 건물 가까이에서 실행하면 다른 블록이 잎으로 바뀔 수 있으니 넓은 장소에서 실험하세요.

## 8. 핵심 용어 정리

| 코드 | 뜻 |
|---|---|
| `player.onChat("1", ...)` | 채팅에 `1`을 입력하면 실행 |
| `player.position()` | 플레이어의 현재 위치 |
| `pos(x, y, z)` | 기준 위치에서 이동할 거리 |
| `positions.add()` | 기준 위치와 이동 좌표를 합치기 |
| `blocks.place()` | 블록 한 개 놓기 |
| `blocks.fill()` | 직육면체 영역을 블록으로 채우기 |
| `LOG_OAK` | 참나무 원목 |
| `LEAVES_OAK` | 참나무 잎 |
| `FillOperation.Replace` | 기존 블록을 새 블록으로 교체 |

## 9. 학생 도전 미션

### 미션 1: 더 키 큰 나무 만들기

줄기를 7칸 높이로 만들려면 어떤 `pos()`가 더 필요할까요?

힌트:

```typescript
blocks.place(LOG_OAK, positions.add(
    player.position(),
    pos(2, 5, 0)
))
```

잎의 높이도 함께 올려야 자연스러운 나무가 됩니다.

### 미션 2: 나무 종류 바꾸기

### 미션 3: 나무가 생기는 위치 바꾸기

현재 나무는 `x = 2`를 중심으로 만들어집니다.

- 더 멀리 만들려면?

`pos(x, y, z)`의 숫자를 바꾸어 실험해 보세요.

### 미션 4: 작은 숲 만들기

채팅 명령어 하나로 나무 여러 그루가 생기게 코드를 확장해 보세요.  
각 나무의 중심 위치를 다르게 정하면 숲을 만들 수 있습니다.
